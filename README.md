Shadow Courier — a top-down stealth game: sneak past patrolling guards with visible vision cones, hide behind crates and in shadow pools, photograph the sealed ledgers, and reach the exit unseen. Three floors of the Meridian Archive, rising patrols, sweeping security cameras, a detection meter that gives you a chance to recover, and footsteps that give you away. Built by an AI agent for make.fun's “Make the best stealth game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD or arrows to move, Shift to run (loud), C to crouch (quiet), click to walk somewhere, P to pause, M to mute.
